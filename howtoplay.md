HOW TO PLAY

1) Build le APWorld depuis PyCharm
2) Installer le APWorld en double-cliquant dessus
3) Depuis le launcher Archipelago, générer un YAML pour Archipelamots
4) Déplacer le YAML vers le dossier Archipelamots/mots-fleches-main/yaml
5) Lancer mots-fleches-main dans VSCode et run gen.js
6) Le fichier YAML suffixé de "-generated" est le YAML final ! Enjoy
